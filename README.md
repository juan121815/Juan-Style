# Juan'Style - Sistema Web para Barbería

Sistema de gestión y reservas web desarrollado para la barbería **Juan'Style**, implementando arquitectura PHP orientada a lógica de control, base de datos relacional MySQL (PDO) y diseño responsivo con Bootstrap 5 en la identidad visual de la marca (blanco, dorado y verde oficial de WhatsApp).

## 🚀 Tecnologías utilizadas
* **Backend:** PHP 8
* **Base de datos:** MySQL (vía XAMPP / phpMyAdmin)
* **Frontend:** HTML5, CSS3, JavaScript, Bootstrap 5

## 📋 Instrucciones de Instalación y Ejecución local
1. Clona este repositorio o descárgalo como archivo ZIP en tu computadora.
2. Coloca la carpeta del proyecto dentro del directorio `htdocs` de tu servidor local XAMPP (`C:\xampp\htdocs\barberia`).
3. Inicia los servicios de **Apache** y **MySQL** desde el panel de control de XAMPP.
4. Importa el archivo de base de datos ubicado en la carpeta **BD** dentro de tu gestor phpMyAdmin.
5. Abre tu navegador web e ingresa a: `http://localhost/barberia/`
